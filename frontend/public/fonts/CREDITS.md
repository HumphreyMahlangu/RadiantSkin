# Typography

Self-hosted font files from the [Google Fonts repository](https://github.com/google/fonts):

- [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif), regular and italic. See `InstrumentSerif-LICENSE.txt`.
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), variable weight. See `Manrope-LICENSE.txt`.

Both fonts are distributed under the SIL Open Font License 1.1. Original license files are included alongside the unmodified fonts. No external font request is made when viewing the storefront.
